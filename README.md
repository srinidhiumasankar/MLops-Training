# Healthcare RAG Bot

A basic Retrieval Augmented Generation (RAG) chatbot built using Flask, FAISS, LangChain and HuggingFace Embeddings.

## Features
- Document retrieval
- Vector search using FAISS
- Flask backend API
- HTML/CSS/JS frontend
- Healthcare knowledge base

## Technologies
- Python
- Flask
- LangChain
- FAISS
- HuggingFace Embeddings
- JavaScript

## Run Backend

python backend/app.py

## Generate Vector Database

python backend/ingest.py

## Run Frontend

Open frontend/index.html using Live Server
